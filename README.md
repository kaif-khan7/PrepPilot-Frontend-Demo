# PrepPilot – Frontend Demo

A standalone, frontend-only demonstration of PrepPilot, an AI-assisted interview preparation platform.

## How to view

Open `index.html` in a web browser, or enable GitHub Pages for this repository to host the demo online.

## Demo sections

- Student dashboard
- Mock interview interface
- DSA practice
- Resume tools
- Progress analytics

## Important note

This repository contains a standalone UI demonstration with sample/demo data. It is separate from the full AscendPrep source project. Backend services, authentication, live AI interviews, and persistent application functionality are not included in this static demo.
